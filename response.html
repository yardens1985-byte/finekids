זה אומר שאני יכול כבר עכשיו:

  • ליצור ריפוזיטוריז (repositories) חדשים
  • לדחוף (push) שינויים
  • לערוך ריפוזיטוריז קיימים
  • לפתוח ולנהל Pull Requests, Issues וכו'

התיקייה הנוכחית עדיין לא מאותחלת כ-git repository. אם תרצה, אני יכול:

  1. לאתחל git בתיקייה הנוכחית (git init)
  2. ליצור ריפו חדש ב-GitHub ולקשר אליו
  3. לדחוף את הקבצים הקיימים

רק תגיד לי איזה שם תרצה לתת לריפו (ציבורי או פרטי), ואני אתחיל.
